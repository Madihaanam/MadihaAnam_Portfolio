# PROJECT REPORT
# PERSONAL PORTFOLIO WEBSITE USING HTML, CSS AND JAVASCRIPT

## Abstract

The Personal Portfolio Website is a frontend web development project created using HTML, CSS, and JavaScript. The project aims to showcase personal information, skills, projects, educational background, and contact details in a professional and attractive layout. The website uses CSS Flexbox, Grid, gradients, hover effects, and media queries to create a modern and responsive design.

## Introduction

This project is developed to understand the fundamentals of frontend web development. The website serves as a personal portfolio to present skills, academic achievements, projects, and professional information. HTML is used for webpage structure, CSS for styling, and JavaScript for interactive functionality. It is a responsive website created for educational and portfolio purposes.

## Objectives

- To create a professional personal portfolio website.
- To understand HTML, CSS, and JavaScript.
- To showcase personal information, skills, and projects.
- To display educational qualifications and achievements.
- To implement responsive web design.
- To add interactive navigation functionality.

## Technologies Used

- **HTML5:** Used to create the structure of the webpage.
- **CSS3:** Used for styling, layouts, colors, animations, and responsive design.
- **JavaScript:** Used to implement interactive features and mobile navigation.
- **Visual Studio Code:** Used as the code editor.
- **Google Chrome:** Used for testing the website.

## Project Structure

```text
Personal-Portfolio/
│
├── index.html
├── style.css
└── script.js
```

The `index.html` file contains the webpage structure, the `style.css` file controls the design and layout, and the `script.js` file manages interactive functionality.

## Features

- Professional navigation bar with menu toggle.
- Hero section with personal introduction.
- About section describing personal information.
- Projects section showcasing completed projects.
- Skills section displaying technical skills.
- Education section with academic details.
- Contact section with contact information and social links.
- Modern dark theme with teal accents.
- Responsive layout for desktop, tablet, and mobile devices.
- Interactive mobile navigation menu.
- Smooth scrolling and hover effects.

## Responsive Design

CSS media queries are used to adjust the website according to different screen sizes. The layout changes for desktop, tablet, and mobile devices. Grid and Flexbox are used to organize content, while the mobile navigation menu is controlled using JavaScript to provide a better user experience.

## Conclusion

The Personal Portfolio Website was successfully developed using HTML, CSS, and JavaScript. This project helped in understanding webpage structure, styling, responsive layouts, DOM manipulation, and event handling. The project demonstrates the fundamentals of frontend web development by creating a professional, interactive, and responsive personal portfolio website.
